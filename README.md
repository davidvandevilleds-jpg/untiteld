## Photo Print Studio (WordPress-plugin)

`wp-content/plugins/photo-print-studio` bevat de WordPress-plugin voor de
bestelwizard: foto uploaden → formaat/DPI-controle → formaat kiezen (met
crop-voorbeeld indien nodig) → montage (losse print / Dibond) → papier
(Hahnemühle Digital FineArt Collection) → afwerking (bij Dibond) → prijs en
bestelling afronden via WooCommerce.

Zie de [plugin-README](wp-content/plugins/photo-print-studio/README.md)
voor installatie-instructies en hoe je producten toevoegt of prijzen
aanpast.
